# TAREFA

Desenvolver a **LearnWave**, uma plataforma web mobile-first para apoio ao aprendizado de língua portuguesa, com sistema de login e chat em tempo real entre professor e aluno.

---

# CONTEXTO

A plataforma será utilizada por alunos do 6º ao 9º ano do Ensino Fundamental e professores. O sistema deve priorizar dispositivos móveis, possuir interface moderna, simples e acessível, além de oferecer comunicação rápida para resolução de dúvidas escolares.

A aplicação será construída utilizando:

- ReactJS
- Vite
- JavaScript ES2022+
- HTML5
- CSS3

---

# TEMA

Educação e tecnologia aplicada ao ensino de língua portuguesa para estudantes do Ensino Fundamental II.

---

# PROBLEMA ATUAL

Muitos alunos possuem dificuldades em português e não conseguem tirar dúvidas rapidamente fora da sala de aula.

Além disso:

- a maioria acessa conteúdos apenas pelo celular;
- plataformas educacionais atuais são complexas;
- falta comunicação simples entre aluno e professor;
- interfaces confusas dificultam o aprendizado.

---

# RESULTADO ESPERADO

Criar uma plataforma:

- moderna;
- intuitiva;
- rápida;
- responsiva;
- acessível;
- organizada;
- escalável.

O sistema deve conter:

- tela de login;
- página institucional da LearnWave;
- chat funcional entre professor e aluno;
- experiência otimizada para mobile;
- interface limpa e amigável.

---

# RESTRIÇÕES

- Desenvolver utilizando ReactJS + Vite;
- Prioridade total para mobile-first;
- Interface deve funcionar entre 320px e 768px;
- Código deve ser componentizado e reutilizável;
- Utilizar boas práticas de acessibilidade;
- Evitar interfaces poluídas;
- Garantir boa performance e carregamento rápido;
- Rotas privadas devem possuir autenticação;
- Inputs e mensagens devem ser validados e sanitizados;
- Não implementar cadastro de usuários na v1;
- Não implementar painel administrativo na v1.
